VAPID Key Generator

This page generates the keys in your own browser — nothing is sent to any server. Open this file by double-clicking it on your computer (no need to upload it to GitHub).

Put these in Code.gs:
VAPID_PUBLIC_KEY = the Public Key above
VAPID_PRIVATE_KEY = the Private Key above

Never share the Private Key and never upload it to GitHub. Both keys must come from the same pair — do not mix keys generated at different times.

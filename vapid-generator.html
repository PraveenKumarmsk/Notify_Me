VAPID Key Generator

Ye page keys aapke hi browser me banata hai — kuch bhi kisi server par nahi jata. Is file ko apne computer par double-click karke kholiye (GitHub par upload karna zaroori nahi).

Code.gs me daaliye:
VAPID_PUBLIC_KEY = upar wali Public Key
VAPID_PRIVATE_KEY = upar wali Private Key

Private Key kisi ko mat dijiye aur GitHub par kabhi upload mat kijiye. Dono keys hamesha ek hi jodi se honi chahiye — alag-alag baar generate ki hui keys mix mat kijiye.
